Privacy Policy

Last updated 4 November 2026.

What it reads

When the account owner signs in with TikTok, this tool can read that account's basic profile, its follower, following, like and video counts, and the view, like, comment and share counts on its public videos.

What it's used for

Only so the owner can review his own account's performance. The data isn't sold, used for advertising or used to profile anyone.

Other people's data

This tool doesn't read other people's accounts, and it doesn't collect information from visitors to this website.

Services involved

Sign-in and data requests run through Composio, which holds the access token. The numbers are then read by the owner's AI assistant. This website is hosted on GitHub Pages, which may keep standard server logs.

Removing access

Access can be withdrawn at any time by removing the app in TikTok's settings, or by deleting the connection in Composio.
